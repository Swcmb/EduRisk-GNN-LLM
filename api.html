API文档

RESTful API接口说明，支持认证、数据管理、学业预警、群体分析、学习路径推荐等功能

接口分类

认证相关接口

用户登录

POST /api/login

POST

请求参数

参数类型必填说明
usernamestring是用户名
passwordstring是密码

请求示例

{
  "username": "admin",
  "password": "admin123"
}

返回示例

{
  "status": "success",
  "message": "登录成功",
  "user": {
    "username": "admin",
    "role": "admin"
  }
}

获取用户列表

GET /api/users

GET

返回示例

{
  "status": "success",
  "users": [
    { "username": "admin", "role": "admin", "enabled": true },
    { "username": "teacher", "role": "teacher", "enabled": true }
  ]
}

添加用户

POST /api/users

POST

请求参数

参数类型必填说明
usernamestring是用户名
passwordstring是密码
rolestring否角色，默认为user

数据管理接口

上传数据文件

POST /upload

POST

请求参数

参数类型必填说明
filefile是数据文件，支持CSV格式

下载数据模板

GET /download-template/{template_name}

GET

路径参数

参数类型说明
template_namestring模板名称：students/grades/attendance/courses
